# Evidence interpretation

The [source index](sources.json) is a citation register. The [claim ledger](claims.md) distinguishes observed source, reported results, proposed design and unestablished outcomes.

The research date is a source observation boundary. Draft 0.3 records exact file commits and content hashes, plus dated PR, release and external-page observations. A release tag is not binary provenance, and a merged pull request is not activation evidence. Commit references pin reviewed source identity; they do not qualify a running integration or make an external page immutable.

Before an experiment, freeze exact commits and dependency versions, node and wallet artifacts, genesis, chain anchors, active rules, protocol profile, storage schema, workload and evidence policy. Record actual command outcomes, failures, interruptions and skipped cases. Do not replace a missing field with a CI badge, a source plan or an estimated activation date.

Document checks cover the repository's structure, links, source identifiers, language, metadata and commit identity. They do not execute or qualify payment or native chain behavior. Private diagnostics and user records are excluded.

The [publication review](publication-review.md) records corrections and review limits. The Word export preserves Draft 0.2; the current Markdown supersedes it. Historical statements about a local draft or earlier source observation are not claims about the repository's current visibility or product readiness.

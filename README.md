# Bitcoin payments and Zenon: research drafts

**Private working draft. Independent research by edgepillar.**

The current study is [Bitcoin checkout for Zenon resource services](studies/resource-checkout/README.md), Draft 0.2, with source observations through 28 October 2026.

It examines an optional BTC checkout for an existing Zenon resource service. Lightning remains the payment rail. The reviewed evidence does not demonstrate a general Zenon advantage over Lightning for ordinary BTC payments.
